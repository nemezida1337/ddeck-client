## 0.9.5-beta — в подготовке

- Рефакторинг без изменения поведения: удалены мёртвые функции мобильного
  слоя (PIN-закрепления, старый pair-button, неиспользуемый launcher) и их CSS.
- Android: WebView освобождает JS-интерфейс, загрузчик, историю и клиентов в
  onDestroy; незавершённый запрос микрофона отклоняется.
- Убраны дубли переводов в панели DSH.
- Починен приватный CI: pnpm-lock соответствует package.json, проверка версии
  учитывает суффикс -beta.
- Версия 0.9.5-beta (905).



- Исправлено моргание клавиатуры при открытии меню «плюс» и повторном нажатии
  на него: кнопки композера больше не снимают фокус.
- Адресованный субагент теперь показывает заметную плашку «Просмотр субагента»
  и не предлагает плюс/док/микрофон, которые всё равно не могли отправить
  сообщение.
- Версия 0.9.4-beta (904).



- Панель DDeck в DSH переработана: диалог с шапкой и закрытием, QR и код
  в две колонки, статус шлюза, список устройств и аккуратные действия.
- Мобильный UI: исправлены скроллинг и нажатия в списке сессий и поиске,
  меню аккаунта, панель добавления рабочей области, поиск, настройки и
  правая панель.
- Сессии gateway сохраняются между рестартами; введён UI-контракт и чек-лист
  финальной беты.
- Версия 0.9.3-beta (903).

- Сессии gateway сохраняются в digest-снимке и переживают рестарт плагина;
  после первого reload нового кода телефоны больше не требуют pairing.
- Режим сессии закреплён portrait: в landscape мобильный интерфейс DSH
  разваливался, поэтому экран сессии не вращается.
- `plugin/relay/health.sh` проверяет публичный relay и перезапускает launchd-
  туннель при 502/504/таймауте.
- Левая панель: верхние строки «Плагины/Автоматические задачи/Ещё» убраны,
  рабочие области подняты сразу под «Новая сессия». Внизу одна строка иконок:
  аккаунт, автозадачи и «Ещё»; внутри «Ещё» — плагины и подключение телефона
  с иконкой телефона и меткой N. Подписи в нижней строке убраны.
- Relay: перед запуском SSH-туннеля освобождается только его удалённый порт —
  после сетевого обрыва старый sshd больше не блокирует `8816` навсегда.
- UI smoke на реальном телефоне: `npm run phone:ui` проверяет композер, док,
  перехват касаний, поиск и safe-area; на Realme 10/10.
- Второй телефон: pairing по паролю проверен, оба телефона одновременно подключены к одному Harness.
- Мобильная панель: скрыта настольная строка DDeck; добавлен «Подключить телефон»
  с паролем, который задаётся на компьютере. Пароль хранится scrypt-хешем,
  попытки ограничены, окно сопряжения открывается только после проверки.
- Поиск по сессиям на телефоне: короткая подпись вместо обрезанной, крестик
  очистки получил область 44 px и больше не закрывает боковую панель.
- DDeck можно перезагрузить через Plugin Manager без перезапуска DSH (HMR
  перечитывает link-плагин); после reload старые сессии требуют повторного pairing.
- Relay: кеш неизменяемой статики на VPS; после первого прогрева перезагрузка
  страницы не тянет JS-бандл через SSH-туннель.
- Иконка DDeck в панели плагинов сделана светлой на тёмном фоне.
- Исправлено ложное «переподключение»: WebSocket `/api/remote.mux` больше не
  закрывается 30-секундным upstream idle timeout; добавлен regression-тест.
- Relay: gzip, HTTP/2 и keepalive к шлюзу; в `docs/RELAY.md` разобрана скорость.
- «Свой сервер»: один адрес/SSH-alias, автоматический публичный origin, статус туннеля.

## 0.9.2-beta — 2026-10-31

- Новый логотип DDeck «Навстречу» и adaptive icon/notification icon.
- Экран подключения: крупная кнопка QR, скрываемый ручной ввод, карточки
  сохранённых компьютеров, статусная плашка и диалог «Как подключиться».
- Диагностика для баг-репорта по долгому нажатию на версию (без токенов).
- Свой сервер: установщик relay для nginx/Caddy, обратный SSH-туннель,
  публичный origin и `docs/RELAY.md`.
- README: быстрый старт, скачивание APK, checksum, подключение через свой VPS.
- Панель DDeck: гайд с шагами и разбором ошибок.

## 0.9.0-beta — 2026-10-24

- Первая публичная бета Android-приложения DDeck и плагина DSH.
- Сопряжение по QR/шестизначному коду, TLS-пиннинг, один телефон — одна запись.
- Чат, инструменты, очередь, файлы, терминал и правая панель; уведомления в фоне.
- Установка плагина одной командой без `pnpm`/`npm install`.
- Android: `app.ddeck.client`, подпись DDeck, targetSdk 36.
