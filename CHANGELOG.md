# Changelog

## 0.9.9-beta — в подготовке

- Полировка после первого публичного релиза: обновление проверки обновлений,
  документация, лендинг и roadmap.
- Исправления по итогам аудита Android/плагина/документации.
- Версия 0.9.9-beta (909).

## 0.9.7-beta — 2.11.2026

- Исправлен запуск DSH Desktop на Windows после переименования пакета:
  клиентский модуль регистрируется как `ddeck-remote`, без дубля `EN_TEXT`
  и падения web-boot.
- Убрана повторная вставка плагина в профиль: пакет сам добавляет свой
  `cordis.patch`, дубль больше не создаётся.
- Добавлена проверка обновлений через GitHub Releases (раз в 12 часов,
  без телеметрии; открывается страница релиза).
- Версия 0.9.7-beta (907).

## 0.9.6-beta — 2.11.2026

- Несколько компьютеров в одном телефоне: «Ещё → Сменить компьютер»
  открывает список сопряжённых машин, добавление по QR/коду и переключение
  без разрыва текущей сессии.
- Исправлен установщик для профиля с пустым `cordis.patch.yml`.
- При смене компьютера старый WebView/Activity закрывается, стек не растёт.
- Версия 0.9.6-beta (906).

## 0.9.5-beta — 1.11.2026

- Рефакторинг без изменения поведения: удалены мёртвые функции мобильного
  слоя и их CSS.
- Android: WebView освобождает JS-интерфейс, загрузчик, историю и клиентов
  в `onDestroy`; незавершённый запрос микрофона отклоняется.
- Убраны дубли переводов в панели DSH.
- Починен приватный CI: pnpm-lock соответствует package.json, проверка версии
  учитывает суффикс `-beta`.
- Версия 0.9.5-beta (905).

## 0.9.4-beta — октябрь 2026

- Исправлено моргание клавиатуры при открытии меню «плюс» и повторном
  нажатии на него.
- Адресованный субагент показывает плашку «Просмотр субагента» и не
  предлагает недоступные действия.
- Версия 0.9.4-beta (904).

## 0.9.3-beta — октябрь 2026

- Панель DDeck в DSH переработана: QR и код, статус шлюза, список устройств,
  аккуратные действия.
- Мобильный UI: исправлены скроллинг и нажатия в списке сессий и поиске,
  меню аккаунта, панель добавления рабочей области, поиск, настройки и
  правая панель.
- Сессии gateway переживают рестарт плагина.
- Версия 0.9.3-beta (903).
