# Как подключить телефон к компьютеру

Короткий путь: установить плагин на Mac → перезапустить DSH → открыть панель
**DDeck** → отсканировать **свежий** QR телефоном.

## 1. Подготовка

- Mac с установленным DeepSeek Harness (профиль `desktop`).
- Android 10+.
- Tailscale на Mac и телефоне, **оба в одном tailnet**.
- APK DDeck из GitHub Releases.

Проверка Tailscale на Mac:

```sh
tailscale status
tailscale ip -4
```

Телефон должен быть виден в `tailscale status` как `android`.

## 2. Плагин на компьютере

```sh
git clone https://github.com/nemezida1337/ddeck-client.git ddeck
cd ddeck
./plugin/install.sh
```

Перезапустите DeepSeek Harness. В интерфейсе DSH появится панель **DDeck**.

## 3. Свежий QR

1. Откройте **DDeck** в DSH.
2. Если код уже показывался — нажмите **«Новый код»**.
3. QR и шестизначный код действуют **5 минут** и только один раз.

Старый QR, скриншот из переписки или ссылка из прошлой установки DSH не подойдут:
после переустановки/перевыпуска сертификата компьютер считается другим.

## 4. Сопряжение

1. На телефоне откройте DDeck.
2. Нажмите **«Сканировать QR с компьютера»** и разрешите камеру.
3. Либо введите адрес компьютера (`https://100.x.y.z:3449`) и шестизначный код вручную.

После успеха приложение запомнит компьютер и при следующем запуске попробует
подключиться само. Приложение можно обновлять поверх — сопряжение сохраняется.

## Если не подключается

| Что видно | Что сделать |
|---|---|
| **«Отпечаток не совпал с приглашением»** | QR/ссылка устарела или это другой компьютер. Откройте DDeck на компьютере → **«Новый код»** → отсканируйте свежий QR. Старую запись компьютера можно удалить кнопкой **«Забыть»**. |
| **401 / «ключ отклонён»** | Код истёк или уже использован. Получите новый код. |
| **«Нет ответа / timeout»** | Проверьте, что Mac не спит, DSH запущен, Tailscale включён на обоих устройствах. |
| **404** | Неверный адрес или порт. Нужен корень `https://…:3449`, без старых путей `/mobile-access/...`. |
| **409** | На компьютере достигнут лимит устройств: в панели DDeck отключите лишние. |
| **«Нет сети» / сертификат** | Проверьте Tailscale и системное время на телефоне; попробуйте «Забыть» и сопрячься заново. |

Если ничего не помогает, пришлите в GitHub Issue версию DSH, Android, текст ошибки
и скриншот — без QR, кода и личного адреса.
