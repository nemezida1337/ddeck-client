# Удалённый доступ через Tailscale

DDeck работает с компьютером напрямую, без собственного сервера. Чтобы подключаться
не только из домашней сети, проще всего использовать **Tailscale**: компьютер и
телефон попадают в один приватный tailnet, а порт `3449` не открывается в интернет.

## 1. Установить Tailscale

- macOS: [tailscale.com/download](https://tailscale.com/download) или `brew install --cask tailscale`.
- Android: Tailscale из Google Play.
- Войдите **в один и тот же аккаунт/tailnet** на компьютере и телефоне.

## 2. Узнать адрес компьютера

```sh
tailscale ip -4
# например: 100.x.y.z
```

В DDeck панель на компьютере сама подставит доступный адрес в QR: Tailscale-адрес
считается первым, LAN — вторым.

## 3. Подключить телефон

1. Включите Tailscale (VPN) на телефоне.
2. Откройте панель **DDeck** на компьютере.
3. Отсканируйте QR приложением DDeck или введите адрес `https://100.x.y.z:3449` и код.

Ожидаемый результат: открывается `/m`, интерфейс DSH работает без предупреждения
о сертификате.

## 4. Проверка

- `tailscale status` — компьютер и телефон в списке;
- `tailscale ping <телефон>` — соединение есть;
- в приложении DDeck сессия открывается, сообщения отправляются.

## Ограничения

- Нужен установленный Tailscale на обоих устройствах и вход в один tailnet.
- Если Tailscale выключен, удалённый адрес `100.x` перестанет отвечать; в домашней
  сети останется LAN-адрес.
- Не используйте `tailscale funnel`/публичный доступ: TLS-пиннинг DDeck рассчитан
  на собственный CA компьютера.
