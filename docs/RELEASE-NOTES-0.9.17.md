# DDeck 0.9.17-beta (917)

UX-спринт по мобильному интерфейсу DSH 0.2.2.

- Safe-area сайдбара и настроек, заголовок настроек не обрезается.
- Единая левая линия и сетка вторичных страниц.
- Навигация настроек аккуратной сеткой, фильтры автоматизации 2×2.
- Заголовки карточек агента не обрезаются, бейджи не ломают строку.
- Компактнее отступы настроек и hero на главной.
- Отключены лишние анимации вторичных страниц (меньше мерцания).
