# DDeck 0.9.3-beta (903) — черновик

Статус: кандидат финальной беты. Не опубликован.

## Что нового

- Панель DDeck в DSH переработана: аккуратный диалог, QR и код в две колонки,
  статус шлюза, список устройств, закрытие и понятные действия.
- Мобильный UI: исправлены скроллинг и нажатия в списке сессий и поиске,
  меню аккаунта, кнопка добавления рабочей области, настройки, правая панель.
- Сессии gateway сохраняются между рестартами плагина; после обновления может
  потребоваться один повторный pairing.
- Версия `0.9.3-beta`, versionCode 903.

## Установка

1. Установить APK `DDeck-0.9.3-beta.apk`.
2. Открыть DDeck, при необходимости отсканировать QR из панели DDeck в DSH.
3. Для второго телефона — задать пароль в панели DDeck и ввести его на телефоне.

## Известные ограничения

- Второй телефон после миграции сессий требует одного pairing.
- Панель DDeck в DSH нужно проверить после полного перезапуска DSH: старый
  клиентский модуль кешируется.
- Release APK ещё не устанавливался на тестовый телефон; debug-сборка
  использовалась для UI-прогонов.
