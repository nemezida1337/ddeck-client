# DDeck 0.10.3-beta (1003)

Срочный фикс кнопки «Аккаунт».

- Кнопка «Аккаунт» в сайдбаре теперь открывает **Настройки** напрямую через React-callback DSH, не пытаясь открыть нативное account-меню (в 0.2.2 оно закрывает drawer).
- WebView загружает страницу с per-launch nonce — старый мобильный слой больше не залипает после обновления.
- Token-gated native bridge и остальные аудиторские фиксы входят в сборку.
- Версия 0.10.3-beta (1003).
