# DDeck 0.11.0-beta (1100)

Адаптация к **DeepSeek Harness 0.2.2-rc.5**.

## Что исправлено

- **Голосовой ввод.** В rc.5 появился экспериментальный плагин голосового ввода:
  микрофон в композере вызывает `getUserMedia`, и без выданного `RECORD_AUDIO`
  экран молча ждал системный диалог. Теперь клиент спрашивает разрешение заранее
  (`microphone.ensure`), показывает свой короткий лист «Разрешить / Открыть
  настройки» и после выдачи разрешения запускает штатную запись DSH. Проверено на
  телефоне: запись → волна → «Стоп» → текст в черновике.
- **Кнопки статистики.** rc.5 переименовал счётчики («Субагенты 2», «Фоновые
  задачи: 2» вместо «2 субагента»). Кнопки субагентов и фоновых задач снова
  появляются в доке и показывают бейджи.
- **Инструменты проверки.** Набор классов rc.5 сериализуется backtick-строками и
  токенами `<hash>_<local>`; парсер и снимок интерфейса обновлены
  (`spec/harness-selectors-0.2.2-rc5.json`), drift `_moreButton` удалён.
- **Поиск сеансов.** В rc.5 раскрытое поле поиска лежит в сетке шапки и
  оказывается под логотипом: касание попадало в «Новую сессию», поиск
  схлопывался. Поле поднято фиксированным оверлеем, нижняя панель скрывается
  сразу по фокусу.
- **Ящик больше не закрывается сам.** Guard пустого ящика принимал ещё не
  отрисованный список за пустоту и закрывал только что открытую панель.
- Версия 0.11.0-beta (1100).
