# С чего начать

Пошаговый путь: от пустого компьютера до DDeck на телефоне.

## Что понадобится

- **Компьютер** с DeepSeek Harness (DSH): macOS, Windows или Linux.
  Нужна версия с поддержкой плагинов (`0.1.5-rc.1+` или `0.2.1-rc.2+`).
- **Android-телефон** 10+ (arm64).
- Один канал связи:
  - локальная сеть — если телефон и компьютер в одной Wi-Fi;
  - **Tailscale** — если нужен доступ из любой сети;
  - свой **VPS-релей** — если Tailscale не подходит.
- 10–15 минут.

> DDeck не устанавливает DSH за вас. Сначала установите и запустите
> DeepSeek Harness, затем ставьте плагин.

## 1. Установите DSH

Установите DeepSeek Harness официальным способом:

- **desktop-приложение** — для macOS или Windows;
- **web/CLI** — `@deepseek-ai/dsh` (если вы уже пользуетесь web-версией).

Запустите DSH и убедитесь, что интерфейс открывается. Дальше нужен профиль,
в который мы поставим плагин:

| Вариант | Профиль |
|---|---|
| Desktop-приложение | `desktop` |
| Web/CLI | `web` |

Если не уверены — откройте настройки DSH или посмотрите на имя профиля в
`~/.dsh/profiles`. В командах ниже замените `web` на нужный профиль.

## 2. Поставьте плагин

### Из npm (рекомендуется)

```sh
dsh plugin --profile desktop add ddeck-remote
```

Для web/CLI-профиля:

```sh
dsh plugin --profile web add ddeck-remote
```

Пакет: [npmjs.com/package/ddeck-remote](https://www.npmjs.com/package/ddeck-remote).

### Из репозитория

Если npm недоступен или нужна локальная разработка:

```sh
git clone https://github.com/nemezida1337/ddeck-client.git ddeck
cd ddeck
./plugin/install.sh
```

Windows (PowerShell 5.1+):

```powershell
git clone https://github.com/nemezida1337/ddeck-client.git ddeck
cd ddeck
powershell -ExecutionPolicy Bypass -File .\plugin\install.ps1
```

Либо добавьте индекс маркета в DSH → **Плагины → Обзор → Источники индексов**:

```text
https://nemezida1337.github.io/ddeck-client/index.json
```

После установки **полностью перезапустите DSH**. В интерфейсе появится панель
**DDeck**. Если панели нет:

- проверьте, что команда выполнялась для того же профиля, который запущен;
- проверьте, что DSH перезапущен, а не просто обновлена страница;
- посмотрите журнал DSH на ошибки загрузки плагина.

## 3. Установите APK

1. Скачайте [DDeck-0.9.9-beta.apk](https://github.com/nemezida1337/ddeck-client/releases/download/v0.9.9-beta/DDeck-0.9.9-beta.apk).
2. Сверьте SHA-256 с [файлом релиза](https://github.com/nemezida1337/ddeck-client/releases/download/v0.9.9-beta/DDeck-0.9.9-beta.apk.sha256).
3. Разрешите установку из этого источника и установите APK.
4. Откройте DDeck.

## 4. Подключите телефон

1. На компьютере откройте DSH → панель **DDeck**.
2. Нажмите **«Новый код»**. Появятся QR и шестизначный код; они живут 5 минут
   и используются один раз.
3. На телефоне нажмите **«Сканировать QR с компьютера»** и разрешите камеру.
4. Либо нажмите **«Ввести адрес и код вручную»** и введите адрес компьютера
   (`https://…:3449`) и код.

После успешного сопряжения DDeck запомнит компьютер и при следующем запуске
попробует подключиться автоматически. Обновление приложения поверх установки
сохраняет сопряжение.

## 5. Доступ из любой сети

### Tailscale

1. Установите Tailscale на компьютер и телефон.
2. Войдите в один и тот же tailnet.
3. Откройте DDeck на компьютере и отсканируйте QR телефоном.

Телефон будет обращаться к tailnet-адресу компьютера; работает и через
сотовую сеть.

### Свой VPS-релей

Если Tailscale не подходит, поднимите **DDeck Relay** на своём VPS. Плагин
держит обратный SSH-туннель, телефон подключается к публичному адресу.
Инструкция: [RELAY.md](RELAY.md).

### Только локальная сеть

Если телефон и компьютер в одной Wi-Fi, Tailscale не обязателен: используйте
адрес компьютера в локальной сети.

## 6. Второй телефон

1. На компьютере: панель DDeck → **«Второй телефон»** → задайте пароль (6–64 символа) → **«Сохранить пароль»**.
2. На первом телефоне: боковое меню → «Ещё» → **«Подключить телефон»** → введите этот пароль.
3. Появится QR и одноразовый код. Второй телефон сканирует QR или вводит адрес и код.
4. Оба телефона получают независимые сессии; первый можно закрыть.

## 6. Несколько компьютеров

1. В боковом меню телефона нажмите **«Ещё» → «Сменить компьютер»**.
2. Нажмите **«Сканировать QR с компьютера»** и подключите второй компьютер.
3. Переключайтесь между компьютерами тем же пунктом меню.

Текущая сессия не разрывается: каждый компьютер хранит свои сессии.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Нет панели DDeck в DSH | профиль, перезапуск DSH, журнал плагина |
| «Не удалось подключиться» | DSH запущен, компьютер не спит, Tailscale/сеть включены |
| «Отпечаток не совпал» | старый QR. Возьмите новый код или нажмите «Забыть» |
| 401 / ключ отклонён | код истёк или использован; получите новый |
| 404 | адрес должен быть корнем `https://…:3449`, без старых путей |
| 409 | лимит устройств; отзовите лишние в панели DDeck |
| Долго грузится | проверьте Tailscale/сеть; перезапустите попытку |

Подробнее: [CONNECT.md](CONNECT.md).

## Обновление и удаление

**Плагин из npm:** повторите `dsh plugin --profile … add ddeck-remote` и
перезапустите DSH.

**Приложение:** DDeck сам проверяет GitHub Releases раз в 12 часов и предложит
открыть страницу обновления. Либо скачайте APK вручную.

**Удаление плагина:**

```sh
./plugin/uninstall.sh
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\plugin\uninstall.ps1
```

Данные сопряжений в `~/.dsh/dsh-remote` не удаляются.
