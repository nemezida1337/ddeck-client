# DDeck: планы после беты

Это **направления**, а не обещания по датам. Порядок будет зависеть от
бета-тестеров, обратной связи и безопасности.

## Сейчас: 0.10.1-beta

- Android 10+;
- Mac, Windows, Linux;
- несколько компьютеров и переключение между ними;
- подключение второго телефона по QR;
- TLS с закреплением сертификата, без облака DDeck;
- npm-пакет `ddeck-remote`, установка в одну команду.

## 0.10.0 — стабилизация

- исправления по итогам первых тестеров;
- надёжность reconnect при смене Wi-Fi/сотовой сети;
- уведомления и фон на агрессивных прошивках;
- мелкие улучшения onboarding и диагностики;
- без новых крупных функций.

## После беты: облако и доступ

### 1. DDeck Cloud

Сейчас для доступа из любой сети нужны Tailscale или свой VPS. В планах:

- управляемый релей, чтобы подключаться без Tailscale и ssh;
- облачная рабочая область DSH, открываемая в мобильном приложении;
- понятная модель тарифов/лимитов;
- возможность остаться полностью self-hosted.

### 2. Групповой доступ

- пароль на компьютер/рабочую область;
- роли: владелец, участник, только просмотр;
- приглашение по QR/коду;
- отзыв доступа для отдельного человека или устройства;
- журнал подключений.

Это должно работать не только для ноутбука, но и для сервера или облачной
рабочей области.

### 3. Коллективная работа

- несколько людей работают с одним DSH-компьютером/сервером;
- у каждого — своя независимая сессия;
- общий доступ к рабочей области в облаке;
- мобильное приложение как основной клиент.

### 4. iOS, iPad и планшеты

- нативное приложение для iPhone/iPadOS;
- адаптация Android-планшетов;
- split view, клавиатура, крупные панели;
- сохранение текущих принципов приватности и TLS.

## Магазины

После стабильной беты и фидбэка:

- RuStore;
- Google Play closed testing;
- store-листинг, Data Safety, политика приватности;
- 1.0 — только после закрытой беты, не раньше.

## Чего не планируем в ближайшее время

- хранение чатов/файлов на серверах DDeck без явного выбора пользователя;
- рекламу и телеметрию по умолчанию;
- автоматические массовые рассылки и «социальные» функции ради роста;
- обещания сроков до проверки гипотез тестерами.
