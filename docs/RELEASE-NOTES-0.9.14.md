# DDeck 0.9.14-beta (914)

Глубокая адаптация мобильного слоя к **DeepSeek Harness 0.2.2-rc.1**.

## Что исправлено

- **Меню:** native drawer DSH владеет геометрией и маской; меню открывается,
  scroll и клики внутри работают.
- **Автоматизация:** кнопка больше не кликает сама себя; цикл меню и серия
  вибраций убраны.
- **Нижняя панель** не блокируется native-маской; кнопки нажимаются.
- **Поиск** открывает drawer до нажатия native search.
- **Аккаунт/настройки:** нативная строка «Меню аккаунта», «Настройки»,
  закрытие системной «назад».
- **Плагины:** overflow-строка находится из меню «Ещё».
- **Кэш:** страница `/m` не кэшируется, приложение передаёт версию в URL.
- **Тесты:** UI smoke обновлён под подписи 0.2.2; 19–20/21 проходят на Realme.

## Проверки

- `npm test` — 63/63.
- `npm run skin:check` — ok.
- Realme, Android 15, DSH 0.2.2-rc.1: меню, scroll, автоматизация, поиск,
  настройки; серия вибраций отсутствует (один импульс 8 мс).
