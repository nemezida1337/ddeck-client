# DDeck 0.9.13-beta (913)

Патч мобильного слоя для **DSH 0.2.2**. После обновления DSH меню перестало
открываться, нижняя панель пропадала, а внизу появлялась жёлтая рамка.

## Что исправлено

- **Меню снова открывается** кнопкой и закрывается нажатием вне панели.
- **Нижняя панель** больше не скрывается из-за ложного определения модалки:
  DSH 0.2.2 объявляет закрытую боковую панель как `role=dialog`.
- **Жёлтая рамка** ушла вместе с ошибочным модальным состоянием.
- **Мобильный слой не кэшируется**: страница отдаётся с `Cache-Control:
  no-store`, а приложение запрашивает её с версией в URL. Старый скин больше не
  залипает после обновления плагина.
- Обновлена документация; версия 0.9.13-beta (913).

## Проверки

- `npm test` — 63/63.
- `npm run skin:check` — ok.
- Realme, Android 15, DSH 0.2.2-rc.1: меню открывается и закрывается
  касанием, нижняя панель на месте, жёлтой рамки нет.
