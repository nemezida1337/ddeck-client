# Security policy

См. [`docs/SECURITY.md`](docs/SECURITY.md).

Коротко: DDeck даёт полный операторский доступ к вашему компьютеру. Используйте
только свой tailnet, не передавайте QR/код, отзывайте лишние устройства. О проблемах
безопасности сообщайте приватно через GitHub Security Advisory, не публичным issue.
